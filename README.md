# Cancer Diagnosis project

This is a Cancer classification + Segmentation app that can perform the mentioned tasks based upon relevant Image of site uploaded by user

## Running This Project

**USING DOCKER (no dependency install required):**

1-- Pull this docker image and run in container (docker pull dani2569/cancer-app:v1.0)

**USING GITHUB:**

⚠️ **Do not use "Download ZIP"** — large files are stored via Git LFS and will not be included.

Correct way:

1-- Download and install Git LFS from (https://git-lfs.com/)

2-- Run these commands to clone files (After that , instructions on how to run the actual website are included in HOW TO RUN.txt) : 
```bash
git lfs install
git clone https://github.com/CtrlAltDeleete/Cancer-diagnosis-app.git
